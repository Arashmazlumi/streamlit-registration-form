# Streamlit Registration Form

A simple user registration form built with Streamlit and SQLite.

## Features
- User registration (Name, Email, Password)
- Email validation using regex
- SQLite database storage
- View list of registered users
- Password field masking

## Installation

1. Clone the repository
2. Run: pip install streamlit
3. Run: streamlit run app.py

## How to Use
1. Enter full name
2. Enter valid email
3. Enter password
4. Click Register
5. Check "Show registered users" to see all users
